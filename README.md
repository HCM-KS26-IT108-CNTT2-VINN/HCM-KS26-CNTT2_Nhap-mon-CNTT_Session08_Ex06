# 🌱 Dự án GreenTech

*Giải pháp công nghệ xanh hỗ trợ phát triển nông nghiệp thông minh và bền vững.*

## 1. Giới thiệu
GreenTech là nền tảng tích hợp IoT và trí tuệ nhân tạo nhằm tối ưu hóa việc sử dụng tài nguyên nước và phân bón cho các trang trại.

## 2. Mục tiêu chính
 Tự động hóa hệ thống tưới tiêu dựa trên dữ liệu cảm biến thời gian thực.
 Giảm thiểu 30% lượng nước tiêu thụ so với phương pháp truyền thống.
 Cung cấp giao diện quản lý trực quan cho người nông dân.

## 3. Công nghệ sử dụng
 **Phần cứng:** ESP32, Raspberry Pi, Cảm biến độ ẩm đất.
 **Phần mềm:** Python, MQTT Protocol, Markdown cho tài liệu kỹ thuật.
